# Vocabulary image attribution

The vocabulary pictograms in this folder are from **Twemoji** maintained by
jdecked and contributors, downloaded from the public GitHub repository at
https://github.com/jdecked/twemoji.

Graphics are licensed under **CC-BY 4.0**. Copyright 2020 Twitter, Inc. and
other contributors. Source code is licensed under the MIT License.

The images are used as language-neutral learning aids for the concepts hello,
water, book, sun, cat, and house.
